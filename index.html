① 견적 기본정보

② 규격별 견적

입금계산기처럼 구분 → 강도 → 슬럼프를 선택하면 규격과 기본단가가 자동 입력됩니다. 직접 입력을 선택하면 특수 규격도 작성할 수 있어요.

계산식: 기본단가 × 적용률(%) → 100원 미만 절사 → 보정값 가감. 보정값은 음수도 가능해요. 단가표에 없는 규격은 직접 입력하세요.

③ 공급자 정보 (자동 저장)

④ 하단 비고

입력 내용은 현재 기기에 저장됩니다. 다른 휴대폰으로 자동 동기화되지는 않습니다.

아이폰: PDF 저장/인쇄 → 공유 또는 인쇄 미리보기에서 PDF 저장. 갤럭시·PC: 인쇄 → PDF로 저장. 인쇄 옵션에서 머리글·바닥글을 끄세요.
